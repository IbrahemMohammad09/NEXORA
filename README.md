# NEXORA

A modern landing page for a digital systems and software brand. NEXORA presents a dark, responsive interface with an animated particle backdrop, software-focused hero section, and solutions showcase.

## Features
- Responsive landing page layout.
- Interactive particle and connected-dot background.
- Digital systems and software hero section.
- Solutions cards and calls to action.
- Animated visual effects using OGL and tsparticles.

## Tech stack
- React 19 and Vite
- Tailwind CSS 4
- OGL and tsparticles
- Lucide React

## Getting started
```bash
git clone https://github.com/IbrahemMohammad09/NEXORA.git
cd NEXORA
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Available scripts
- `npm run dev` — start the development server.
- `npm run build` — create a production build.
- `npm run preview` — preview the production build.
- `npm run lint` — run ESLint.

## Deployment
A GitHub Pages workflow is present in `.github/workflows/deploy.yml`. Review the workflow configuration and repository Pages settings before deployment.

## Project structure
- `src/pages/Home.jsx` — landing page composition.
- `src/sections/` — hero and solutions sections.
- `src/component/` — navigation, effects, and solution cards.
- `public/` — static assets.
